# Pixel Scene Gallery (v2)

Painterly pixel-art scenes made with Pixel Studio, plus the original pixel engine test reel.

This is the **v2** branch, published at https://pyraco.github.io/pixel-scene-gallery-v2/. It adds:
- jointed, animated figures
- the original engine's film finish and neon-noir look
- the Sunken Temple scene
- a real Colosseum awning
- a castle built into its mountain

The first version stays on `main` at https://pyraco.github.io/pixel-scene-gallery/.

- index.html: the gallery hub and the engine test reel
- studio-gallery.html: twelve Pixel Studio scenes, four variants each, with their prompts and settings
- studio.html: the Pixel Studio app
